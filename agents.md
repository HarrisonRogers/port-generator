# Agent Instructions

## Project Context

This project is a generator for simple portfolio websites. It uses a user's
GitHub profile and a small amount of personal information to understand who
they are, what they do, their notable projects, and their career history.

The generated output should feel like a concise personal portfolio: clear,
professional, and focused on helping someone quickly understand the user's work,
skills, projects, and career timeline.

## Code Conventions

- Component file and folder names should use camelCase.
- Keep exported React component identifiers in PascalCase.
